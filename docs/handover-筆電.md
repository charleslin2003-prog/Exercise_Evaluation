## 1. 筆電第一次設定

```bash
git clone https://github.com/charleslin2003-prog/Exercise_Evaluation.git
cd Exercise_Evaluation
git checkout dev          # ← 所有工作都在 dev，master 是正式版、不要碰
```

需要 **node**（跑測試腳本與各種驗證架）與 **python**（文字處理）。沒有其他相依，
沒有 build step。

本機看畫面：

```bash
python3 -m http.server
# http://localhost:8000/Analysis.html?t=wanfang-7f3a2c
# http://localhost:8000/Start.dc.html?t=wanfang-7f3a2c
```

⚠️ 網址一定要帶檔名，根路徑永遠 404（沒有 `index.html`）。

### 跑回歸測試

```bash
export EVAL_KEY_MAIN=<萬芳預設場次的分析金鑰>
bash scripts/smoke.sh
```

金鑰在**租戶註冊表的 `分析金鑰` 欄**。沒設就跳過需要金鑰的檢查，不會紅。
**每次重貼後端之後先跑它**，退出碼 0 再往下做。

## 5. 接下來要做的

### 還沒開始：把「產生評核報告」搬到分析平台

業主 2026-10-12 要求的六項改動裡唯一還沒動的。**規模遠大於其他五項**，所以
單獨列出來。

技術上的硬限制先講清楚：**瀏覽器沒有 `DocumentApp`**，不可能在網頁裡產生
Google 文件。所以只能做成「網頁按一下、後端去跑」，那表示：

- `Report.gs` 要額外部署成 Web App（加 `doPost` 入口）
- 現在 `reportStart`／`reportContinue` 的分段執行要改成 HTTP 往返
- **那個網址一旦公開，任何人都能叫它產報告並寫檔案到雲端硬碟**，所以必須加金鑰
- 而 `Report.gs` 現在**不需要部署**正是它存在的理由（見 `CLAUDE.md`），
  這等於放棄那個優點

開工前值得先跟業主確認：真正想要的是不是只有「不用切換到試算表去按」。

### 還沒驗證

- **註冊表硬擋（`02d5ed1`）** —— 今天最重要的修正之一，只有刻意把註冊表改壞
  才測得到。步驟在對話紀錄裡，核心是：清空 `分析金鑰` 那格表頭 → 等 120 秒 →
  帶 `?t=` 的連結應該回「系統設定目前有問題…」，而**不帶** `?t=` 的連結仍須正常。
  兩步都要驗：證明「會擋」，也要證明「只擋該擋的」。
- **`Report.gs` 的時間預算切分**與**圖表降級路徑** —— 三次實跑都一次就完成、
  `Charts` 也都可用，所以這兩條從來沒走到。不需要特地製造。

## 6. 會浪費你時間的坑

這些都是這幾天真的踩過的：

| 坑 | 症狀 | 真正原因 |
|---|---|---|
| 貼錯 Apps Script 專案 | `Cannot call SpreadsheetApp.getUi()` | 從 Apps Script 首頁新建的是**獨立專案**。一定要從該試算表「擴充功能 → Apps Script」進去 |
| 在編輯器按「執行」開對話框 | 執行記錄一直轉到逾時 | 對話框只能從試算表選單點。編輯器沒有試算表 UI 可以顯示 |
| 跑 `onOpen` 想拿授權 | 跑完了但權限還是不足 | 加選單不需要 `script.container.ui`。要跑**會開對話框的函式**才會觸發授權 |
| 改註冊表後沒反應 | 看起來沒生效 | 有 **120 秒**快取 |
| 重複用同一個演習代號測試 | 新場次一開場就顯示已完成 | `localStorage` 的 key 是 `醫院/場次:代號`，**沒有隨機成分**。每輪換新代號 |
| 新建的紀錄分頁找不到 | 分頁列上看不到 | `insertSheet` 插在**目前作用中分頁後面**，不是最後。按 F5 並左右捲 |
| 推送後測試站沒更新 | 還是舊版 | Vercel 建置有時要兩三分鐘。`Age: 0` 才是新的 |

## 7. 工作習慣

- **一律在 `dev` 做**，`master` 凍結
- commit 可以直接做，**push 前要先問**
- 新增任何後端程式、內部文件或暫存檔，**同時加進 `.vercelignore`** ——
  Vercel 會把 repo 裡每個檔案都公開，那個檔案是公開／非公開的唯一分界
