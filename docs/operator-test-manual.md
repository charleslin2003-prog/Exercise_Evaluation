# 步驟 0：事前檢查

**全部在瀏覽器網址列完成，不需要任何工具。** 把網址貼進網址列按 Enter，回來的是一片文字
（JSON）。不用看懂全部，照下面指定的字串用 `Ctrl+F` 搜就好。

> 💡 手機或小螢幕上 JSON 會擠成一團，**用電腦做步驟 0**。
>
> 💡 **Firefox 會把 JSON 畫成一棵可以收合的樹**，收起來的部分 `Ctrl+F` 搜不到。
> 做下面的外洩檢查前，先按那個檢視器上方的「**原始資料**」分頁。Chrome／Edge
> 直接顯示整片文字，不用做這件事。

### 0-1. 註冊表那兩列是你以為的樣子

**要做**：開註冊表 `1oab1W2UFo71qeZ-fEz_cYtE__3dNFw_OG_7TzrUZdfk`，看 `租戶註冊表` 分頁。

**應該看到**〔實測 10-13〕：正好**兩列**資料，`醫院代號` 都是 `wanfang-7f3a2c`，
`演習代號` 分別是 `2026a`／`2026b`，兩列 `啟用` 都是 `Y`，
`開放送出起` = `2026/10/13`、`開放送出迄` = `2026/10/17`，只有 `2026a` 的 `預設演習` 是 `Y`。

**不對的時候**：

| 看到什麼 | 可能的原因（全部列出來，不要只查第一個） |
|---|---|
| 多了第三列、或代號不是這兩個 | 有人（或精靈）新增過場次。先確認那一列是誰建的，**不要直接刪** —— 刪掉預設演習那一列會讓 `?t=` 不帶 `?ex=` 的連結整家醫院報錯 |
| 兩列都是 `預設演習=Y` | 只帶 `?t=` 的連結會回「**這家機構有多列被標為預設演習，請只保留一列。**」清掉其中一列那一格 |
| `開放送出起` 跟 `開放送出迄` 是**同一個時間點** | 時間窗長度為零＝那一場從來沒開過（不是「開完關了」）。這正是 10-12 踩過的狀況 |
| 兩格都空白 | 空白＝**永遠開放**，不是永遠關閉。評核官會挑錯場次而且真的送得出去 |

### 0-2. 後端活著，而且路由是通的

把這三條**依序**貼進網址列：

**(a) 裸網址**（不帶任何 `?`）：

### 0-4. 兩個 Apps Script 專案的屬性

**指令碼屬性是每個專案各自獨立的。** 報告有兩條路，各自讀自己專案的屬性：

| 路線 | 專案在哪 | 這次要不要用 |
|---|---|---|
| **儀表板**按「產生 Google 文件」 | 獨立部署「演習評核報告 Web」 | ✅ 這次走這條 |
| **試算表選單**「演習評核報告」 | 容器綁定在設定試算表上（擴充功能 → Apps Script） | ❌ 這次不走（見 0-C 第 4 項：它是舊版，三項潛能會印 `—`） |

**要做**：開「演習評核報告 Web」那個專案 → 左側 ⚙ **專案設定** → 捲到「指令碼屬性」。

網頁這條路線會用到的屬性只有這四個：

| 屬性名稱 | 必填？ | 這次要是什麼 |
|---|---|---|
| `REPORT_API_URL` | 必填 | 0-B 表上那條**後端**網址（`AKfycbzQLAJCv3…/exec`，以 `/exec` 結尾） |

### ⚠️ 關於「重複送出」—— 請不要把它當成測試項目

很容易想這樣測：回手機把同一項再送一次，看列數會不會重複。**不要這樣判斷，因為
「列數又多了一批」在這裡是正確行為，不是 bug。**

程式的去重是**針對同一次送出的自動重試**（手機收訊不好時，同一次按下去的送出最多會自己
重試三次，三次帶著同一組流水號，後端只收第一次）。你**手動**退回去重新按一次送出，那是
一次**全新的**送出、全新的流水號，後端會老老實實再寫一批列。

- 想看到去重生效，必須製造「送出送到一半斷線又接回來」—— **手動做不出來，也不必做。**
- 所以**同一題在紀錄表裡出現兩次是正常的**。分析平台只取**最後一次**，所以數字不會因此
  被灌水。
- 真正該回報的是相反的情況：**明明只按了一次送出，卻出現兩批一模一樣的列**。

**不對的時候**：

| 看到什麼 | 可能的原因（全部列出來） |

| 一列都沒增加 | **你在看錯的分頁**（0-C 第 7 項，先檢查這個）；或送出其實失敗了只是你沒看到紅字；或那一場的註冊列指到別的紀錄檔案；或你剛剛送的是另一場 |
| 列數增加了但數字對不上 | 你中途改過項目、或送出了不只一次；也可能是那一項的題數跟你記得的不一樣 |
| `問題ID` 變成日期 | 那一欄不是純文字格式。**程式送出的是文字**，是 Sheets 自己轉的 |
| 有 `觀察紀錄` 欄但內容是空的 | 那一場的設定檔把 `啟用觀察紀錄` 關掉了（手機上根本沒有那個欄位）；或你沒填；或你填了但送出的是另一題 |
| **沒有** `觀察紀錄` 這一欄 | 這一欄是**選填**的，沒有就整欄安靜略過 —— 評核官打的文字會被直接丟掉，不會報錯 |
| 只按一次送出卻多了兩批一樣的列 | **這個才要回報**，附上送出時間與人員代號 |

  `…/Analysis.html?t=wanfang-7f3a2c&ex=2026b&key=<2026b 那一格的值>`（值去註冊表
  `2026b` 那一列的 `分析金鑰` 欄複製，開頭是 `UE8QYl`）。

  > 「只給被選到的那一場用」：帶著 `2026b` 的金鑰之後，同一個分頁切回 `2026a` 就變成
  > `2026a` 讀不到。**一個分頁同時只能看一場**，除非走上面「建議」那條。
  >
  > 這把金鑰**刻意不寫進本文件** —— 這份文件在公開的 git repo 裡，寫進來就收不回去了。

**切回 `2026a`**（原本那個沒有補 `&key=` 的分頁）：資料應該恢復正常。

> 切換場次時**網址列全程不會出現 `key=`**。這是刻意的：網址列裡的金鑰會被瀏覽紀錄記住，
> 列印時還會被印在紙上。

| 看到什麼 | 可能的原因 |

# 步驟 4：列印檢視報告（方案A）

這是**內部快速檢視**用的，不是歸檔文件。要歸檔的那一種是步驟 5。

**要做**：按抬頭的「**列印檢視**」。

**應該看到**：

1. 畫面重排成一份由上而下的報告：封面 → 列印設定提示卡 → 報告摘要 → 綜合結果 →
   4S → 三項潛能 → 覆蓋率 → 觀察紀錄彙整 → 資料品質 → 評核方法 → 附錄C。
2. **網址列的 `?key=` 不見了。** 這是刻意的 —— Chrome 列印時會把網址印在頁尾，
   不清掉就等於把金鑰印在紙上。
   **代價是：這之後按重新整理，要重新貼一次帶金鑰的連結。**
3. 提示卡上有**兩個**勾選框：
   - 「**匿名模式（以「評核官 1、2…」取代人員代號）**」—— **預設打勾**，評核官顯示為
     「評核官 1」「評核官 2」…，不是 `A01`。取消勾選會跳一個確認視窗寫明後果 ——
     那是刻意的一道關卡，不是多餘的。
   - 「**附上逐題強弱排序（含學習潛能題目）**」—— **預設不勾**。不勾就沒有那一章。
4. 封面有**六個**可以直接打字的欄位：**演習地點／報告版次／文件編號／製表／審核／核定**。
   ⚠️ **它們不會被存到任何地方**，重整就沒了。要留就先列印或另存 PDF。

**然後 Ctrl+P 預覽**，確認三件事：

- ⚠️ **Chrome 的「背景圖形」必須打勾**，否則 3D 柱狀圖與 4S 色譜會**印成全白**。
  這個勾選框在列印對話框的「更多設定」裡。
- 表格沒有被切掉（捲到第一頁以後的列要印得出來）。
- 圖表沒有擠成一團。

**老實講清楚兩件事**：

- **這個檢視沒有頁碼，而且做不到。** Chrome 沒有提供任何讓網頁自己編頁碼的機制；
  唯一的頁碼來源是 Chrome 自己的頁首頁尾，而那個會連網址一起印出來。
  **要頁碼、要目錄、要文件編號，就是步驟 5。**
- 「評核官明細」那張逐人分數表**不會出現在這裡**，列印時也被強制隱藏。
  那是刻意移除的，不是漏掉。

按「**返回儀表板**」離開。

|---|---|---|
| **時間用完了** | 標題變「**已收尾（部分完成）**」；檔名帶「**（部分完成）**」；文件第一頁有「草稿 — 產生未完成（本份報告尚未完成，請勿分發）」橫幅；`報告快照` 的狀態欄是「部分完成」 | **數字不會掉** —— 全部統計值在寫第一個字之前就已經落進 `報告快照`。想要完整版：請維護者把範本裡幾個選用錨點刪掉、或把時間預算調小，再產一次（會做出一份**全新的**報告） |
| **中途把分頁關掉了** | 什麼都沒有，報告停在半成品 | 那份草稿留在雲端硬碟裡。**重新整理過的分頁接不回去**（接手需要一組只發給原分頁的憑證），這跟選單那條路「關掉對話框就接不回去」是同一個限制 |
| **同一場已經有一輪在跑** | 在**同一個分頁**裡，「產生 Google 文件」只會是灰的、提示寫「報告產生中…」，按不下去。在**另一個分頁／另一台電腦**上按，才會看到 `REPORT_BUSY` 那段說明，底下一顆「**查看那一輪的狀態**」（唯讀，**不能接手**） | 同一場同時只允許一輪。若那一輪真的已經斷了，**約 15 分鐘後會自動失效**，之後就能重新產生。⚠️ **試算表選單的「重設產生狀態」清不掉這一輪** —— 那是另一個專案的紀錄，兩邊互不相通 |
| **這一輪失敗了，而且是在原本那個分頁裡** | 面板上出現「**捨棄這一輪**」 | 按它，不用等 15 分鐘。已經建立的草稿文件**不會**被刪。⚠️ 這顆鈕**只有原本那個分頁有**（後端用一組只發給它的憑證認人）。分頁重新整理過就沒了，只能等 15 分鐘 |
| **「產生期間資料已經變動…」** | 整輪中止 | 訊息本身就寫出兩種可能：**有評核官剛送出新的分數**，**或設定試算表被編輯過**。兩個都要確認（0-C 的兩條通則）。排除之後再產一次 |
| **`unauthorized`** | 面板直接說明這一頁用的金鑰跟那一列的不同 | 見 0-C 第 1 項 |
| **連按兩次「開始產生」** | — | **不會蓋掉好的那一份。** 每一輪都是複製一份全新的文件，程式從不寫進既有的報告檔案。最壞的結果是兩份各自獨立的報告 |

# 步驟 6：收尾

### 6-1. 關掉一場演習

**要做**：註冊表那一列的 `啟用` 改成 `N`。**就這樣。**

| 改成 `N` 之後 | 結果 |
|---|---|
| 評核官用**帶 `?ex=` 的直接連結**打開評核單 | 「這場演習已結束，不再開放評核。」 |
| 評核官從**場次清單**進來 | 根本點不到那一列（它被收進「顯示已結束場次」裡，而且是灰的） |
| 評核官按送出 | 被拒絕，訊息同上 |
| 你開分析平台 | **照常可以看**（報告本來就是演習結束後才做） |
| 場次清單 | 列在「顯示已結束場次（N）」後面，而且**點不下去** |

另一種做法是把 `開放送出迄` 填一個已經過去的時間，時間一到自動關。兩者可以同時用。

⚠️ **明年複製這一列重辦時，`紀錄試算表ID` 或 `紀錄分頁名稱` 一定要換新的。**
封存只擋填答與送出，**分析仍然讀得到這一列** —— 兩列指到同一張紀錄分頁，兩場演習的
分數會混在同一份報告裡。系統現在會硬擋這件事（兩列都會被判無效、連結回「註冊資料有問題」），
但它擋下來的時候你已經在找別的原因了。

### 6-2. 哪些東西要留著

| 留 | 為什麼 |
|---|---|
| **`報告快照` 分頁** | 它是「這份報告當時說了什麼」唯一機器可讀的副本，也凍結了當時的標籤。**永遠只新增、不覆寫。** |
| **`_報告暫存` 隱藏分頁** | 畫圖用的暫存，留著就好，不用管它 |
| **紀錄試算表的所有列** | **沒有任何還原機制。** 分析平台就是直接讀整張表 |
| **已產生的 Google 文件與 PDF** | 產出的文件**是可以編輯的** —— 結論、建議、改善行動這些系統生不出來的內容，直接在那份文件上補，再自己另存 PDF |
| **這次測試留下的評分列** | 它們就是下一次測試的基準資料。要清請先跟維護者確認 |

### 6-3. 下一輪測試之前

- **換一個沒用過的人員代號**（0-C 第 6 項）。
- 要徹底重來，就在手機上清掉該網站的瀏覽資料 —— 「已完成」標記存在手機裡，不在雲端。

# 附二：回報清單

跑完之後，**把下面這幾項送回給維護程式的人**。這些是外面推測不出來、只有實機跑過才知道的
東西 —— 尤其第 1、3 項。

1. **「圖表能力探測」那一行的完整文字**
   —— 檢查設定裡那一列，以及報告附錄C 裡對應的那一行，**兩邊都要**。
   〔實測 10-13〕檢查設定那邊說**雷達圖（RADAR）可用**（選單那條路 10-09 也這樣回報，
   見 `docs/manual-test-checklist.md` M3）；但「檢查時可用」跟「實際每一張圖都畫得出來」
   是兩回事 —— M3 那次也記著，capability 全綠只排除得掉降級鏈的第一段，後面幾段是逐張圖
   拿不到圖檔時才走的。**所以附錄C 那一行才是真答案。**

2. **任何一個 ❌**，連同它整段中文說明（**原文照抄，不要摘要** —— Apps Script 的錯誤訊息
   常常最後一句才是真正的原因）。

3. **報告裡「三項潛能」那一章的實際樣子。**
   這一項特別要看：試算表選單那條路目前是舊版程式（0-C 第 4 項），**會**把三項潛能印成
   `—`、`n=0`。儀表板這條路用的是新版，**不應該**這樣，但沒有人驗證過。
   所以請明講你是**從哪一條路**產的、三項潛能印出來是什麼。

4. **「警告與降級紀錄」整個區塊的全文**（沒有警告也請說「沒有」—— 「沒有降級」本身就是
   一個有價值的結果）。

5. **整個流程花了幾分鐘**，以及進度卡上「章節 N / 21」最後停在幾。
   **還有一件特別的事：這一輪總共被切成幾批？**（畫面上會停頓、進度往前跳一段。
   `docs/manual-test-checklist.md` M3 記載選單那次「一輪就跑完」，所以**多批執行這條路
   至今沒有人走到過**，走到了請說。）

6. **檔案最後落在哪個資料夾、擁有者是誰**（0-C 第 3、5 項各自的驗證）。

7. **報告上的數字與分析平台對照的結果**（相同／不同；不同的話兩邊各是多少）。

8. **任何你覺得「怪但說不上來」的地方。** 這一項不是客套 —— 之前有一次問題就是這樣被抓到的，
   它不在任何檢查項目裡。
