# Dispatch 端對端測試手冊

給**能驅動瀏覽器的雲端 agent** 執行。用使用者的角度，把整套系統從「建立一場演習」
一路跑到「看分析、產報告」，中間真的填答、真的送出分數。

這份手冊假設執行者：

- **能**開網頁、點擊、輸入、讀畫面文字
- **不能**用 curl 連 `script.google.com`（沙箱代理會擋 403，2026-10-09 實測）
- **不會**點 Google 的 OAuth 同意畫面（遇到就停下來回報）
- **沒有**相機，所以 QR 碼不掃，改從精靈畫面複製網址

能用 curl 的環境請改跑 `scripts/smoke.sh`，那 18 項不要在這裡重做。

## 2. 已知的操作陷阱（先讀，可以省掉重跑）

1. **精靈的「醫院」下拉在自動化點擊下會悄悄跳回第一個選項**（2026-10-09 實測）。
   選完之後**一定要回讀一次確認值對不對**，不對就改用鍵盤操作。
2. **新建的紀錄分頁不會出現在分頁列最後面**，`insertSheet` 插在目前作用中分頁後面。
   找不到就按 F5 並把分頁列往左右捲。
3. **不要在 Apps Script 編輯器按「執行」。** 所有對話框都只能從試算表選單點開。
   編輯器執行 `showModalDialog` 會一直轉到逾時。
4. **`onOpen` 不需要手動跑。** 選單是開啟試算表時自動掛的，F5 即可。
5. **每一輪測試都要換一個新的演習代號**（`e2e01` → `e2e02` → …）。「已完成」標記存在
   localStorage，key 是 `醫院代號/演習代號:評核官代號`，**沒有任何隨機成分**。重複用
   同一個代號，上一輪的進度會在新場次一開場就跳出來，看起來像「還沒填就已完成 10/10」。
   這不是 bug，但會讓你以為資料有問題。不換代號就要先清 localStorage。

## E2E-1. 建立一場新演習（精靈，含複製設定檔）⬜

這是整條鏈的起點，也是「每場演習有自己的時間地點題目」的唯一實現方式。

0. 選單 `演習場次管理` → `設定說明（指令碼屬性）`，確認 **`SETUP_SITE_BASE` 正好是
   `https://exerciseevaluationtest.vercel.app`**。不是就停止並回報 —— 精靈產出的三條網址
   是用這個值組出來的，它指到正式站的話，你後面每一步都會在正式站上操作。
1. 開「**租戶註冊表**」試算表 → F5 → 選單 `演習場次管理` → `新增一場演習…`
2. 先按 **「只檢查，不建立」**，記下目前的健全性狀態（之後要比對有沒有被你弄壞）
3. 回填表單：

| 欄位 | 填什麼 |
|---|---|
| 醫院 | **既有** → `clinic-9b4e1d`（用分院，資料量小好驗證）**選完回讀確認** |
| 演習代號 | `e2e01` |
| 顯示名稱 | `E2E測試01（用完即刪）` |
| 開放送出起 | **今天的日期，時間設成現在的前一小時** |
| 開放送出迄 | **明天** |
| 紀錄分頁名稱 | 留空（自動變成 `評核紀錄_e2e01`） |
| 設定檔 | **複製一份新的設定檔** |
| 演習日期 | 今天 |
| 地點 | `E2E 測試地點` |
| 說明 | `端對端測試用` |
| 設為預設 | **不要勾** |

⚠️ 時間窗一定要讓「現在」落在區間內，否則後面送不出分數。

4. 按「建立場次」

**預期**：

- [ ] 畫面出現兩張 QR 與三條網址
- [ ] 結果說明裡有「已複製設定試算表」「已新增紀錄分頁」
- [ ] **把三條網址全部複製下來**，尤其分析平台那條（含分析金鑰，後面要用）

**驗收**：

- [ ] 雲端硬碟多了「E2E測試01（用完即刪）｜設定」
- [ ] 三條網址都以 `https://exerciseevaluationtest.vercel.app` 開頭
- [ ] 紀錄檔多了 `評核紀錄_e2e01` 分頁，**表頭與既有分頁完全相同**
      （表頭是從紀錄檔裡第一個非空分頁抄來的，不是固定 7 欄。把精靈結果說明裡
      「已新增紀錄分頁「…」，表頭 N 欄」那一行原文抄下來回報）
- [ ] 註冊表多一列
- [ ] 複製出來的設定檔「演習資訊」分頁有 `演習名稱`／`演習日期`／`說明`（地點在說明裡）

## 回報格式

逐項給勾選狀態，加上：

1. **「圖表能力探測」那一行的完整文字**（最重要，外部推測不到）
2. **警告／降級紀錄全文**
3. E2E-5c 三個驗收點各自過或不過
4. 任何**畫面上的**異常：數字是 NaN、圖表空白、版面被切、文字擠在一起
5. 失敗項目請附**完整**錯誤訊息，不要摘要 —— Apps Script 的錯誤常常最後一句才是真正原因
6. **任何你覺得「怪但說不上來」的地方**。2026-10-09 那次就是這樣抓到下拉選單跳回
   第一項的問題，那不在任何檢查項目裡

- 任何需要碰正式站、正式試算表、正式 `/exec` 的情況
- 任何會刪到不是這次測試建立的資料的情況
